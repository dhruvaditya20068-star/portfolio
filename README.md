# Aditya Sharma — Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript, based on the supplied website screenshots.

## Typography

- **Logo:** Technor Extralight
- **Name and title:** JetBrains Mono (88px and 24px on desktop)
- **Body/context text:** IBM Plex Sans (18px)

JetBrains Mono and IBM Plex Sans are loaded from Google Fonts. The logo is displayed using your supplied logo image, so the original lettering is preserved without requiring the Technor font file.

## Files

- `index.html` — page content and structure
- `css/style.css` — layout, typography, colours, and responsive styles
- `js/script.js` — JavaScript entry point
- `images/profile.jpg` — your supplied monochrome portrait
- `images/logo.png` — your supplied `ad1tya.com` logo image

## Preview locally

Open `index.html` in a browser with an internet connection to load Google Fonts.

## Publish with GitHub Pages

1. Create a GitHub repository. For a user site, name it `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. After deployment, visit `https://YOUR-USERNAME.github.io`.

This is a static site and does not require Wix, a database, or a build process.
